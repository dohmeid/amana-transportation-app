# Amana Real-Time Bus Tracker 🚌

Welcome to the Amana Real-Time Bus Tracker! This is a web application designed to provide live tracking of bus routes, display up-to-date schedules, and offer a seamless user experience for commuters. Never miss your bus again!

## ✨ Features

- **🗺️ Live Map Tracking**: View the real-time location of buses on an interactive map.
- **📅 Dynamic Schedules**: Get up-to-the-minute arrival times for all bus stops on a selected route.
- **📱 Responsive Design**: A clean and intuitive interface that works beautifully on both desktop and mobile devices.
- **🚍 Multi-Line Support**: Easily switch between different bus lines to view their specific routes and schedules.
- **ℹ️ Detailed Information**: Click on a bus or stop to get more details, like status, capacity, and next stop information.

## 🛠️ Tech Stack

This project is built with a modern and robust technology stack:

- **Framework**: Next.js (React)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Mapping**: React-Leaflet with OpenStreetMap
- **Font**: Geist

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have Node.js (v18 or later) and a package manager like `npm` or `yarn` installed.

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/amana-transportation-app.git
    cd amana-transportation-app
    ```

2.  **Install dependencies:**
    Choose your preferred package manager.
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Open the application:**
    Open http://localhost:3000 with your browser to see the result!
